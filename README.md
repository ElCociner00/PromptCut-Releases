# PromptCut para Windows

Este repositorio público contiene únicamente instaladores de PromptCut en blanco y archivos de actualización. El código fuente y los documentos de trabajo se conservan en un repositorio privado.

Descarga únicamente una versión estable publicada en [Releases](https://github.com/ElCociner00/PromptCut-Releases/releases). Las versiones que consultaban el repositorio privado requieren instalar manualmente una vez el instalador de transición. Las siguientes actualizaciones consultan este destino público.

Los instaladores no incluyen cuentas, sesiones, credenciales privadas ni contenido de ningún usuario. SHA256SUMS.txt permite verificar los archivos publicados. El hash no sustituye una firma de editor.
